# Tech Stack Overview

- **Frontend**: Next.js + TypeScript (Pages Router)
- **Gateway**: Node.js + Express + proxy middleware
- **Profiles/Reviews**: Node.js + Express + PostgreSQL + Redis
- **Benchmarks/Analytics/Worker**: Python + FastAPI + pytest + scikit-learn
- **Messaging**: Kafka + Zookeeper
- **Storage**: PostgreSQL (system of record), Redis (read cache)
- **Infra**: Docker Compose, Kubernetes manifests, Terraform starter
- **Testing**: Jest, pytest, contract tests, Playwright scaffold
